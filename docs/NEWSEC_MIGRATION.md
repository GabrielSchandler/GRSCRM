# Migração Visual Newsec

## Critério

Uma tela só é marcada como revisada quando mantém o fluxo, dados e permissões
originais, passa pela validação de tipos e lint, e é conferida no navegador.

## Base comum

- [x] Shell autenticado, navegação, cabeçalho, rodapé, paleta e estados claro/mobile.
- [x] Compatibilidade visual para superfícies, inputs, tabelas, botões e cores legadas.
